# Security Policy

Thank you for helping us keep the OSS Scanner enrolment repository and its tools secure.

## Reporting Security Issues

This repository is maintained by [Anthropic](https://www.anthropic.com/).

The security of our systems and user data is Anthropic's top priority. We appreciate the work of security researchers acting in good faith in identifying and reporting potential vulnerabilities.

Our security program is managed on HackerOne and we ask that any validated vulnerability in this repository or its tools be reported through their [submission form](https://hackerone.com/4f1f16ba-10d3-4d09-9ecc-c721aad90f24/embedded_submissions/new). Please do not open a public issue or pull request for a vulnerability.

## Anthropic Bug Bounty

Our Bug Bounty Program Guidelines are defined on our [HackerOne program page](https://hackerone.com/anthropic).
