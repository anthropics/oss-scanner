# dev-sidecar 威胁模型（OSS Scanner）

## 项目概况

dev-sidecar 是本地 HTTPS 中间人代理：在本机监听 HTTP/HTTPS 代理端口，动态签发证书，按配置对特定域名做 DNS 优选、SNI 改写、请求重定向/替换，并为 npm/pip/git 等工具写入镜像或代理配置。GUI 基于 Electron，内核 `@blue-frontier/dev-sidecar` 与代理引擎 `@blue-frontier/mitmproxy` 位于 `vendor/ds-core` 子模块。

## 重点扫描范围

1. **代理协议解析**：HTTP 请求行/头/分块编码、CONNECT 隧道、WebSocket、HTTP/2 升级处理，畸形输入下的内存与状态机安全。
2. **TLS/证书**：动态签发证书的 SAN/序列号/有效期处理；上游证书校验；CA 私钥文件权限；证书缓存键冲突。
3. **DNS 与 SNI 处理**：预设 IP、DoH/DoT 响应解析、SNI 改写导致的证书/主机名混淆；域名匹配正则的回溯风险。
4. **拦截规则引擎**：`server.intercepts`、whiteList、重定向与响应替换的路径/正则匹配；配置合并（默认/远程/用户）中的原型污染与越权覆盖。
5. **插件与 Shell 调用**：npm/pip/git 插件拼接命令、写配置文件；`sudo-prompt` 提权命令的注入面；Windows/macOS/Linux 分支的路径与参数转义。
6. **更新链路**：release 资产下载、重定向跟随、增量包解压路径穿越、写入 `resources` 的权限与完整性校验。
7. **Electron 边界**：渲染进程 `nodeIntegration` 下的 IPC 桥；远程内容（网页诊断 webview）与本地权限的隔离。
8. **日志与反馈包**：日志脱敏是否遗漏凭据；打包上传路径穿越；临时文件权限。

## 对抗性输入

- 任意 HTTP/HTTPS 请求与响应（包括畸形头、超长 URI、异常分块、TLS 握手异常）。
- 恶意或错误的远程配置、用户配置、`running.json`。
- 不可信的镜像/重定向目标与下载资产。
- 本机其他进程写入的日志、配置文件、CA 文件。
- 网页诊断页面加载的第三方站点内容。

## 明确不在范围

- `packages/gui/extra/` 下预编译的 `EnableLoopback.exe`、`sysproxy.exe`（无源码）。
- 第三方依赖自身漏洞（请按依赖报告，不重复计入本项目）。
- 用户主动关闭 TLS 校验（`proxy.verifySsl=false`）导致的风险。
- 需要本机管理员权限才能利用、且不属于代理逻辑的本地提权。

## 严重性建议

- **Critical**：无需交互的远程代码执行、可绕过 TLS 校验读取/篡改任意流量、CA 私钥泄露。
- **High**：代理进程内存破坏、任意文件写入/删除、提权命令注入、更新包路径穿越。
- **Medium**：拒绝服务（单请求打挂代理）、配置越权覆盖、敏感信息写入日志。
- **Low**：需要本地权限或极端配置才可利用的问题、信息泄露但影响有限。

## 报告偏好

- 附最小复现：请求/响应样例、配置片段、复现命令；能给 PoC 脚本更好。
- 补丁以最小改动为原则，说明影响面与回归风险。
- 同一根因的多个入口请合并为一条，注明所有受影响路径。
