# Report format

Provide a short title, affected revision and configuration, severity with a
concrete impact rationale, and the attacker prerequisites. Identify the entry
point and relevant source locations. Clearly distinguish reproduced observations
from hypotheses. For consensus findings, specify the network, activation rules,
validation mode and whether valid proof of work is required.

Include a minimal deterministic local reproducer, exact commands, expected and
observed outcomes, and the test output. Describe restart or persistent-state
requirements when relevant. State the proposed correction and compatibility
implications. Avoid duplicate descriptions of the same root cause.
